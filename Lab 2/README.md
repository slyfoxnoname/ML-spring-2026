# Лабораторна робота №2: Методи класифікації (Варіант 4)

Дослідження та порівняльний аналіз моделей машинного навчання для бінарної класифікації кредитного скорингу на базі датасету **UCI Credit Approval (`crx.data`)**.

---

## 📌 Параметри варіанта
* **Датасет:** `crx.data` (UCI Credit Approval)
* **Цільова змінна ($Y$):** остання колонка (`A16`), бінаризована як `1` (`+`, схвалено) та `0` (`-`, відмовлено)
* **Факторна змінна:** `A13`, а також інші категоріальні регресори (`A1`, `A4`, `A5`, `A6`, `A7`, `A9`, `A10`, `A12`)
* **Числові ознаки:** `A2`, `A3`, `A8`, `A11`, `A14`, `A15`
* **Розподіл вибірки:** 80% — train, 20% — test (зі стратифікацією за класами `stratify=y`)
