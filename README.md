# Лабораторна робота: Регресійний аналіз (Варіант 4)

Проєкт містить повний пайплайн регресійного аналізу на базі набору даних `NAICExpense.csv`: побудову базової оцінки найменших квадратів (ОНК), регуляризацію (Ridge, Lasso), поліноміальне моделювання та бенчмарк методів оптимізації.

---

## 📌 Параметри варіанта
* **Датасет:** `NAICExpense.csv` (365 валідних спостережень після очищення від пропусків)
* **Цільова змінна ($Y$):** `EXPENSES` — операційні витрати
* **Регресори ($X$):** `RBC`, `STAFFWAGE`, `AGENTWAGE`, `LONGLOSS`, `SHORTLOSS`
* **Розподіл вибірки:** 80% — навчання (train), 20% — тест (test), фіксований `random_state=42`

---
